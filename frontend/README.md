# Fluxo Mobile

Aplicativo React Native criado com Expo e TypeScript.

## Executar

    npm install
    npm start

No terminal do Expo, pressione `w` para abrir a versão web, `a` para Android ou leia o QR code pelo Expo Go em um celular.

## Estado atual

As telas usam dados demonstrativos locais para permitir navegar sem o backend: onboarding, login visual, cadastro, recuperação de senha, dashboard, registro textual, gravação simulada, confirmação, histórico, resumo e perfil.

O backend atual ainda não possui autenticação, detalhes/edição/exclusão de lançamentos nem sincronização offline. Essas ações devem ser conectadas quando as rotas correspondentes existirem em `../backend/`.
