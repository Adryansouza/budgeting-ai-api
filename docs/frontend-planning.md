# Fluxo Mobile

Este diretório abrigará o aplicativo React Native do Fluxo.

Tecnologias previstas: React Native, Expo, TypeScript e Expo Router. O app terá uma única base de código para Android e iOS, com exportação web opcional. As telas só serão criadas depois que uma direção visual for escolhida a partir dos mockups do plano `plans/00-fluxo-mobile-monorepo.md`.

O aplicativo consumirá a API em `../backend/` por HTTPS. A URL da API será configurada por ambiente e nunca ficará fixa no código.
